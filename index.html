A CONCRETE DEBUGGING CASE

DNS worked.
Connections didn’t.

DOCKER NETWORKING / CODESPACES
SYMPTOM
The repository documents service names resolving while container-to-container TCP connections timed out.
CAUSE & FIX
A stale iptables-legacy forwarding policy alongside Docker’s nftables rules. The repair script conditionally adds a Docker user-bridge forwarding rule and checks whether it already exists.
VERIFICATION & LIMIT
The runbook restarts Compose and checks the services. The linked CI verifies application flows on a clean runner; it does not reproduce this Codespaces firewall fault.

PROJECT SCOPE

Practice, not a production claim.

This is a personal engineering project, tested through Docker Compose and CI. There is no claim here of a production cloud deployment, real customers, measured uptime, or load-tested capacity.

The tests exercise specific workflows. They do not prove complete fault tolerance, exactly-once processing, or production readiness. Kubernetes and monitoring files show configuration work, not a verified production installation.
